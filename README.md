# Siemens filesystem library
#### Щито это
Библиотека для работы с файловой системой в FULLFLASH: чтение, а также запись — создание и замена файлов, создание каталогов, удаление файлов и пустых каталогов.

##### Поддерживаемые платформы:
- SGOLD
- SGOLD2
- SGOLD2 ELKA \
Требует тестирования
- EGOLD с Card-Explorer \
Требует тестирования. Только чтение

SGOLD хранит имена в 8-битной кодировке языка телефона — CP1252 для западноевропейских языков, CP1251 для кириллических, CP1250 для центральноевропейских, — а имена с символами, которых в ней нет, в UTF-8. Кодировку задаёт `set_codepage()`, по умолчанию CP1252; по ней имена и читаются, и записываются.

## Тесты
Тесты используют GoogleTest (`libgtest-dev`) и собираются с `-DBUILD_TESTS=ON`:
```
~/libffshit > cmake -DBUILD_TESTS=ON -B build .
~/libffshit > cmake --build build
~/libffshit > cd build && ctest
```
Тесты записи пишут в фуллфлеши `CX70v56lg3.bin`, `SL65v49lg1_TIM.bin`, `S75v40lg1.bin` и `EL71v41lg91.bin`, сохраняют их и читают обратно. Укажите каталог с ними в переменной `FFSHIT_TEST_FULLFLASHES` или положите их (или симлинк на каталог с ними) в `tests/fullflashes`. Без фуллфлешей эти тесты пропускаются.

Проверку тем, что записанное понимает прошивка телефона, — в эмуляторе и по OBEX — делают тесты ffnightman.
